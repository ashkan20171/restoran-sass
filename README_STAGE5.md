# Stage 5 — Backend foundation

Added `/server` with ASP.NET Core 8, SQL Server EF Core Identity schema, protected management endpoints, pending reservation intake, menu pricing in independent USD/toman fields, and an optional server-side AI chat endpoint. See `server/README.md` for setup and production limitations.

The original English-first static website and Persian RTL pages are preserved unchanged. **The frontend is not yet connected to the new API**, and its demo bookings, menu and chatbot remain browser-only. No live checkout or confirmed reservations are claimed.
